# 🎂 Mom's Birthday Cinematic Mini-Movie

🎬 A fully animated, interactive birthday web experience built with pure HTML, CSS and JavaScript.

Live Site:  
👉 https://momsbirthdaymovie.netlify.app/

---

## ✨ Features

- 🕯 Interactive candle-blow start (hold to extinguish)
- 💥 Realistic firework celebration with explosion sound effects
- 🎶 Background music with smooth fade-in
- ❤️ Floating love emojis and animated hearts
- 📸 Full-screen cinematic photo slideshow (no cropping)
- ⌨️ Cursive typewriter animated quotes
- 🎆 Visual + audio celebration before movie begins
- 📱 Mobile responsive

---

## 🛠 Tech Stack

- HTML5
- CSS3 (animations & transitions)
- Vanilla JavaScript
- Web Audio API (custom firework sound generation)
- Canvas API (firework visuals)

---

## 🚀 Deployment

Deployed on Netlify.
